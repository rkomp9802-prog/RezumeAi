# Конструктор резюме и мини-сайт портфолио

Редактор резюме с живым предпросмотром, тремя шаблонами, PDF-экспортом, JSON-копиями, AI-помощником на Gemini и сборкой статического сайта-портфолио в ZIP.

Без базы данных, регистрации и авторизации: все данные хранятся только на устройстве пользователя (localStorage и IndexedDB).

## Установка

```bash
npm install
```

## Development

```bash
npm run dev
```

Откройте http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и укажите ключ:

```env
GEMINI_API_KEY=
```

- `GEMINI_API_KEY` — ключ Google Gemini API ([получить](https://aistudio.google.com/apikey)). Нужен только для AI-помощника; без него остальное приложение работает.
- Ключ используется только на сервере — в маршруте `/api/ai` — и не попадает в браузер (переменная без префикса `NEXT_PUBLIC_`).
- `.env.local` не коммитится.

Необязательно: `GEMINI_MODEL` — основная модель (по умолчанию `gemini-3.5-flash`; при перегрузке автоматически используются запасные).

## Возможности

- Несколько резюме: создать, переименовать, скопировать (со своими изображениями), удалить, переключаться.
- Пошаговый редактор из 11 шагов на React Hook Form + Zod; форма и предпросмотр видны одновременно, на телефоне — переключатель «Форма | Предпросмотр» (от 320px).
- Записи и разделы: добавление, скрытие, удаление, порядок перетаскиванием (мышь, касание, клавиатура).
- Автосохранение с задержкой 700 мс и статусами «Сохранение… / Сохранено / Ошибка сохранения»; отмена и повтор (50 шагов, Ctrl+Z / Ctrl+Shift+Z).
- Фото и изображения проектов: JPEG/PNG/WebP до 5 МБ, обрезка, замена, удаление; хранятся в IndexedDB.
- Шаблоны Classic, Minimal, Modern; цвет акцента, шрифт (Inter, Geist, Roboto, Source Sans 3, Merriweather — с кириллицей), плотность, показ фото.
- PDF формата A4 (несколько страниц) по выбранному шаблону — только резюме, без интерфейса.
- JSON: экспорт (изображения в Base64 только внутри файла) и импорт с проверкой через Zod — импорт добавляет новое резюме и не трогает существующие.
- AI (Gemini): создать «О себе», выделить сильные стороны, улучшить описание опыта, исправить ошибки, изменить тон, адаптировать под вакансию. Запуск только по кнопке, результат — окно «Исходный текст / Предложение AI» с кнопками «Применить» и «Отменить». AI получает минимум данных (без имени, контактов и фото) и не должен придумывать факты; если в ответе появились числа, которых не было в данных, показывается предупреждение.
- Сайт-портфолио: предпросмотр и `portfolio.zip` (`index.html`, `styles.css`, `assets/`). Сайт работает из распакованной папки без Node.js и сети. Чтобы получить публичную ссылку, загрузите папку на статический хостинг: GitHub Pages, Netlify, Cloudflare Pages, Nginx.
- «Удалить все локальные данные» — все резюме, настройки и изображения (localStorage и IndexedDB), с подтверждением.

## Как устроено

Главное правило: одна модель `Resume` и одна цепочка данных.

```text
resumeSchema (Zod) → Resume
        ↓
  store (единое состояние, undo/redo, автосохранение)
        ↓                      ↑
  форма (RHF)            AI (после подтверждения)
        ↓
  buildResumeView (порядок, видимость, даты, ссылки)
   ├── предпросмотр (Classic / Minimal / Modern)
   ├── PDF (@react-pdf/renderer)
   ├── портфолио: renderPortfolioSite → iframe и index.html в ZIP
   └── JSON-экспорт (сама модель Resume)
```

```text
src/
  app/                 страницы: / (мои резюме), /editor; API: /api/ai
  components/
    editor/            шаги редактора, формы, списки, AI-кнопки, верхняя панель
    resume/            HTML-шаблоны резюме и предпросмотр A4
    portfolio/         предпросмотр сайта-портфолио
    library/           список резюме
    common/            поля: фото с обрезкой, месяц, теги; диалоги
    ui/                shadcn/ui
  features/
    resumes/           store и действия
    images/            обработка изображений, object URL с освобождением
    export/            PDF, JSON, ZIP
    ai/                клиент /api/ai
  lib/
    resume/            схемы, типы, значения по умолчанию, миграции, selectors, прогресс, дизайн-токены
    storage/           localStorage и IndexedDB
    portfolio/         генератор HTML/CSS сайта
    ai/                контракт, промпты, клиент Gemini (сервер)
public/fonts/          TTF-шрифты резюме (для предпросмотра, PDF и ZIP)
```

- Порядок записей — их позиция в массиве; порядок и видимость разделов — массив `sections`. Отдельных полей `order` нет, чтобы не было двух источников правды.
- Версия данных — `schemaVersion` (сейчас 1). Миграции для localStorage и импортируемых JSON — в `src/lib/resume/migrations.ts`.
