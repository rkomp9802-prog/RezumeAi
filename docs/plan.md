# План: конструктор резюме и мини-сайт портфолио

ТЗ: `resume_portfolio_builder_spec.md`. Исполнитель всех задач — Claude (бесплатные модели через OmniRoute были недоступны на момент старта).

## Ключевые решения

- **Одна модель.** `resumeSchema` (Zod 4) в `src/lib/resume/schema.ts` — единственный источник структуры; тип `Resume = z.infer<typeof resumeSchema>`. Хранилище, импорт, форма, AI и все рендеры работают с ним.
- **Порядок записей = позиция в массиве**, порядок и видимость разделов — массив `sections: { id, hidden }[]`. Отдельных полей `order` нет, чтобы не было двух источников правды.
- **Единое представление для вывода.** `buildResumeView(resume)` (`selectors.ts`) применяет правила видимости, порядка, форматирования дат и ссылок. Его читают HTML-шаблоны, PDF, портфолио и ZIP — правила нигде не дублируются.
- **Портфолио = одна функция.** `renderPortfolioSite(view, assets)` генерирует HTML и CSS. Предпросмотр показывает этот же HTML в `iframe`, ZIP кладёт его в `index.html` — предпросмотр совпадает с архивом.
- **Единое состояние.** Модульный store на `useSyncExternalStore` (без дополнительных библиотек): текущее резюме, история undo/redo (50 шагов, слияние быстрого ввода), автосохранение с debounce 700 мс и статусами.
- **React Hook Form** — представление над store: ввод пишет в store, внешние изменения (undo, AI, импорт, переключение) сбрасывают форму.
- **Изображения** — Blob в IndexedDB, в резюме хранится только id. Object URL выдаёт кэш со счётчиком ссылок и отзывает их. Неиспользуемые картинки удаляются сборкой мусора при запуске и удалении резюме (так undo не ломает фото).
- **Шрифты** — одни и те же TTF (Inter, Geist, Roboto, Source Sans 3, Merriweather; 400/700, с кириллицей) в `public/fonts` для предпросмотра, PDF и ZIP.
- **PDF** — `@react-pdf/renderer`, загружается лениво по нажатию; WebP конвертируется в JPEG, т.к. react-pdf не читает WebP.
- **AI** — `POST /api/ai`, ключ только на сервере, в Gemini уходят только поля, нужные действию. Ответ всегда показывается как «Исходный текст / Предложение AI» с кнопками «Применить» и «Отменить».

## Проверено в браузере

Ввод и автосохранение, восстановление после перезагрузки, undo/redo (набор слова — один шаг), три шаблона и дизайн в живом предпросмотре, фото (загрузка, обрезка 600×600 WebP в IndexedDB, отказ для GIF и файлов >5 МБ), PDF (A4, 1 и 2 страницы, кириллица, фото), ZIP (относительные пути, без скриптов и Next.js), JSON (экспорт с Base64, импорт как новое резюме, отказ для битого JSON и будущей версии), AI (минимальные данные, без выдуманных фактов, «Применить» и отмена), копия/переименование/удаление резюме со сборкой мусора изображений, порядок разделов с клавиатуры, скрытие разделов, «Удалить все локальные данные», 320px без горизонтальной прокрутки на всех 11 шагах, `npm run build`, отсутствие ключа в клиентском бандле.
